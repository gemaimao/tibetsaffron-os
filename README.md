# Brand Content OS — A Knowledge Operating System for Brand Teams

**（Brand Content OS —— 面向品牌团队的知识操作系统）**

**Version**: v14.0 Platform Architecture  
**Governance Version**: V2.2 Scenario-Controlled Content Production (Active Enforced)  
**Status**: Production Pilot Active  

> **Master Definition**:  
> **Brand Content OS 不是一个 AI 工具，而是一套把品牌知识持续转化为品牌内容和品牌资产的操作系统。**  
> *(三核心闭环：品牌知识 Knowledge ──► 品牌内容 Content ──► 品牌资产 Assets)*

---

## 🏆 5 大终极冻结黄金原则 (5 Frozen Golden Principles)

### 原则一：平台优先 (Platform First)
用户面对的永远是 **Brand Content OS**，而不是 NotebookLM、ChatGPT 或 Claude。所有 AI 工具与大模型全部降级为后台可插拔的 AI Adapters。

### 原则二：输入优先 (Input First, Not Folder First)
用户不用思考放哪个目录、打什么标签、属于哪个模块。用户只负责：“**Bring Anything In. We Understand the Rest.**”，剩下的交由系统自动分类与语义标注。

### 原则三：Repository 永远保持纯净 (Repository is Canonical)
绝不允许 RAW 素材未经清洗与确认直接进入核心库！固定遵循防污染闭环：
$$\text{Inbox (输入层)} \xrightarrow{\text{ AI 自动理解 }} \text{推荐归档卡片} \xrightarrow{\text{ 人工一键确认 } (\checkmark)} \text{Repository (规范资产)} \xrightarrow{\text{ Output }} \text{COM (业务产出)}$$

### 原则四：Brand Skill 可复制 (Brand Skill Reusability)
天旺藏红花不是项目的终点，而是第 1 个落地验证的 **Brand Skill**。未来茶、葡萄酒、文旅、生物科技等行业均复用同一个 Brand Content OS。

### 原则五：OS 才是真正的 MVP (OS Platform is the True MVP)
本阶段的核心任务不是做完某单个项目，而是**证明 Brand Content OS 是一个真正能像优秀品牌部门一样稳定工作的操作系统**。

## 🏛️ 三层平台架构与 AI Adapters

```text
                               用户 (User)
                                    │
            ┌───────────────────────┴───────────────────────┐
            ▼                                               ▼
    微信 / 飞书 / 钉钉                               Web / App / API
─────────────────────────────────────────────────────────────────────────
      【第一层：Brand Content OS 核心平台 (Core Product & IP)】
─────────────────────────────────────────────────────────────────────────
 • Ingestion Platform (输入中心 / Inbox) — "Input First. Zero Learning Cost."
 • Knowledge Repository (知识库 / 资源库) — 集中管理所有品牌资产 (`/Core`)
 • Knowledge Kernel (知识内核) — 由 Entity, Concept, Principle, Framework 构成
 • Knowledge Governance (治理规则) — 不可撤销的红线与生命周期
 • Production Workflow (生产工作流) — 一键按需组装业务内容
─────────────────────────────────────────────────────────────────────────
      【第二层：AI 能力适配器层 (AI Adapters Execution Layer)】
─────────────────────────────────────────────────────────────────────────
 • NotebookLM Adapter (长文档检索与语音播报 AI 适配器)
 • GPT / Claude / Gemini Adapter (大模型推理与生成 AI 适配器)
 • GraphRAG / Neo4j Adapter (知识图谱与拓扑检索适配器)
 • OCR / Speech / Multimodal Adapter (多模态解析适配器)
─────────────────────────────────────────────────────────────────────────
```
