# Overview

Release v0.1 是 Brand Content OS 的第一次正式发布。

它标志着整个 Brand Content OS 从概念设计阶段正式进入 Repository 管理阶段。

本次 Release 建立了：

- 品牌知识操作系统（Brand Content OS）的基础架构
- Repository 组织方式
- Developer 开发规范
- Communication Module
- Knowledge Module
- Visual Framework
- Data Framework
- Brand Framework

自本版本开始，Brand Content OS 将采用 Git Repository 进行长期维护，并作为整个品牌知识体系的唯一可信源（SSOT）。

Repository 将持续演进，但 Release v0.1 永久保留。
