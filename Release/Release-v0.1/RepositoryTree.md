# Purpose

RepositoryTree.md 是整个 Brand Content OS Repository 的导航索引（Repository Index）。

它用于：

- 新开发者快速了解工程结构
- AI Agent 快速定位模块
- NotebookLM 建立知识入口
- Git Release 浏览
- Repository 巡检

任何新成员进入项目，应首先阅读本文件。

# Repository Principle

RepositoryTree.md 不保存业务内容。

它只负责：

告诉人和 AI：

整个 Brand Content OS 在哪里；

每一部分放在哪里；

下一步应该去哪里。

它是整个 Repository 的导航地图，也是 Agent 的第一入口。
