# Release v0.5 — Impact Metrics & Proof Chain Architecture

## 🔗 影响力证据与证据链原则 (Proof Chain Principle)

> **“不要问单个数据有没有，而要问这个数据能不能形成一条完整的【影响力证据链（Proof Chain）】。”**

摒弃“有效促进乡村振兴”这类无修饰词的空洞形容词，全面建立无修饰词的硬核数据证据链：

$$\text{区域基线数据} \xrightarrow{\text{ 企业的用工/投入 }} \text{覆盖率比例} \xrightarrow{\text{ 发放工资/支出 }} \text{户均纯增收} \xrightarrow{\text{ 事实结论}}$$

---

## 📊 影响力指标体系 (Impact Metrics - `IMP`)

建立可以无限复用于**政府汇报、ESG 报告、招商 PPT、党媒报道、投资者关系 (IR)** 的固定数据资产：

* **`IMP-1000` 就业指标链**：长期岗位、季节岗位、劳动力覆盖率
* **`IMP-2000` 收入指标链**：年工资支出、人均工资、户均增收
* **`IMP-3000` 产业指标链**：合作农户、合作社、带动面积
* **`IMP-4000` 财税指标链**：纳税、村集体收益、本地采购
* **`IMP-5000` 培训指标链**：培训人次、技术培训次数、持证人数
