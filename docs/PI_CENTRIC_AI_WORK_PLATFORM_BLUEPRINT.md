# 基于 Pi Agent 为核心的个人与品牌超级 AI 工作平台建设蓝图

- **发布时间**：2026-09-21
- **架构主脑**：Pi Agent (System 2 综合决策与调度)
- **极速决策层**：TypeSafe Jev (System 1 毫秒级裁判与无损裁剪)
- **桌面工作台**：Orca ADE (Git Worktree 任务隔离宿主)
- **多模态交付**：Jianying Headless 11.4.2 (剪映无头自动化流水线)
- **移动指挥面**：飞书 / Lark 原生会话中枢
- **知识核心**：Brand Content OS (BCOS 品牌资产与双轨中台)

---


## 五大落地实施阶段（基于 Jev 优先度评估）

### 阶段一：稳态核心（L1 会话保鲜与 Jev 无损裁剪）
- **核心目标**：彻底解决 Pi 长链路高频交互下的 Context 膨胀与失忆问题。
- **实施动作**：
  1. 激活已安装的 `pi-typesafe` 扩展与 TypeSafe API Key；
  2. 挂载 `fast-jev-compaction` 机制，在长会话超过 30k tokens 时触发 Jev 的 `DROP/KEEP` 概率过滤；
  3. 保留代码路径与报错原文（verbatim），剔除过期读取与冗余输出，保证会话百轮不卡顿。

### 阶段二：移动指挥（L2 飞书全能控制台常态化）
- **核心目标**：实现“Mac 在家安静跑，手机在拉萨随手派活”。
- **实施动作**：
  1. 守护进程稳定化：`caffeinate -s` 防休眠 + LaunchAgent 守护进程自启；
  2. 飞书多模态交互打通：已实现文字、语音、图片即时接收与流式推送；
  3. 任务异步通知机制：长任务（如全站编译、视频导出）完成后，自动推送飞书卡片。

### 阶段三：知识与数据中台（L3 BCOS 双轨导入与资产治理）
- **核心目标**：打通现场泥土真实性与全球科研权威性。
- **实施动作**：
  1. **轨道一（现场真实性）**：`mobile.html` 移动端录入，即时同步至 `Inbox/`；
  2. **轨道二（限定情报矩阵）**：利用 Jev-use 动作流，定向抓取知网、PubMed、行业标准；
  3. **Jev 资产治理**：调用 `typesafe_evaluate` 对每条流入素材执行秒级分类（COM/KNO/VIS/DAT/BRD）与合规打分；
  4. **SSOT 双写沉淀**：审核通过后同步落盘为 `db.json` 与标准 Markdown。

### 阶段四：桌面多兵种并行（L4 Orca ADE 宿主与 Git 隔离）
- **核心目标**：告别单兵作战，实现一人指挥多 Agent 军团而不打架。
- **实施动作**：
  1. 安装配置 Orca ADE 桌面环境；
  2. 将 Pi、Codex、Claude Code 配置为 Orca 的协同 Agent；
  3. 针对不同项目任务（如“修改天旺官网风土页”、“编写帕竹葡萄酒调查脚本”）自动分配独立 Git Worktree，避免多 Agent 互踩文件。

### 阶段五：视频流水线（L5 剪映 11.4.2 无头视频工厂）
- **核心目标**：打通品牌短视频与农田纪实的无人值守剪辑。
- **实施动作**：
  1. 部署 `jianying-headless`，锁死剪映桌面客户端版本为 11.4.2；
  2. 接入豆包 ASR 毫秒级音频对齐接口；
  3. 封装 Pi 专属 Skill `video-pipeline`：输入文案与现场音频，自动切除气口废话，生成标准剪映工程草稿，后台导出 MP4。
