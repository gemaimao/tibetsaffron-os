02｜技术决策：保留 Vite，多页渐进重构

推荐：现有 Vite 多页结构 + 语义化 HTML + 独立 CSS + 原生 ES Modules + 审核后的结构化内容。首页不强制迁移到 Vue，不新引入 Next.js、大型组件库或新的后端框架；已有 Vue 依赖留给原有模块，不扩大迁移面。

  • 首屏正文静态可读：编译阶段把审核后的标题、段落、图片与链接写入 HTML；关闭 JavaScript 仍可阅读五段及访问详情。
  • 交互渐进增强：JS 只负责季节/月份切换、导航状态、图片查看、公告抽屉；不让基础内容依赖 API 或大型视觉运行时。
  • 样式隔离：新增 .tw-site 作用域与 --tw-* 变量；不重置 OS/录入页的全局样式。
  • 唯一首页源：根目录 index.html 作为唯一维护入口；site/index.html 和 portal.html 变为经过确认的兼容入口，不再维护三套首页正文。
  • 独立前台构建：新增前台专用配置，禁止导入原配置中的开发 API 插件。预览只绑定本机回环地址，产物中不包含 Core、Inbox、原始资料及内部导出包。
  • 首页不依赖旧重型场景：移除首屏对旧空间叙事脚本的依赖；旧视觉能力不作为新版首页交付前提，也不在本期新增相关多媒体内容。

04｜视觉方案：产地、人物与产品优先

采用用户指定的纳帕酒庄式叙事取向，不复制任何具体网站：大幅真实摄影、克制排版、留白、编辑式短标题、清晰的创始人和团队线索。弱化原有“仪表盘、密集指标、科技炫技”的首页观感。

暖白纸底深植物绿文字少量花紫标记少量花丝红重点
  • 首图使用已批准的高清实拍，不默认使用现有概念全景图；画面叠字应保证对比度。
  • 年份轴与一年环是导航和理解工具，不用来填补真实摄影缺口。
  • 桌面宽幅照片 + 文字；手机改为竖向阅读，不截断人物面部和手部，不横向溢出。
  • 字体以系统中文字体为可靠底座，不以外部字体加载成功作为页面可读前提。
  • 图库浏览、菜单与抽屉支持键盘、焦点返回、关闭按钮和无障碍标签。

必须挂起核验的锚点

  • 1765 / 261年：已由业务方确认口径：1765年赵学敏《本草纲目拾遗》出版首定“藏红花”名，以2026年计距今261年。
  • 95.2%：缺指标定义和原报告，不能推断成纯度、含量或成功率。
  • 30万打款：先确认用途、时间和凭证，不自动等同年度工资或乡村贡献。
  • 农残 / 246 / 报告号：重庆色价/地标报告与深圳农残检测分别绑定；“未检出”必须保留项目、方法和批次边界。
  • 多糖 / 多酚：展示产品类别可以先做；人体降血糖或降尿酸疗效不得从斑马鱼研究外推。研究数据仅在证据详情中配实验模型说明。
  • 两段式 / 设施农业：历史探索、现行工艺和未来研发分开；不可从旧页面直接继承未经确认的当前生产描述。

开发策略：版式、导航、数据结构和交互可以先生成；未确认内容在内部预览标待补。对外发布必须是经批准的表达，或明确不发布该条，不能用看似真实的占位数字补齐。

07｜分批代码生成：每批都能单独验收

批次生成内容依赖 / 验收 / 停止条件
A · 隔离与契约记录现有未提交差异；逐文件建立备份/补丁边界；创建独立前台构建配置、五段数据契约、内容白名单和测试入口。验收：预览不运行原 API，不触发自动导出/提交，不暴露 Core/Inbox；缺失字段在校验中显式报错。禁止对用户已有改动执行整仓恢复。

C · 一纵一横交互缘起十年轴；四段共享季节状态；手机四季条；必要时根据实测数据再升级月份级。依赖 B。验收：章节与季节不混淆；切换不重置页面焦点；缺月度数据不插值；键盘可操作。
D · 五段下钻与系统入口重构四个已有详情页，新增劳作页；保留证据页；抽离公告展示；最小修复 OS/录入入口。依赖 B/C及相应批准内容。验收：五段主 CTA 可达；每页有返回对应主段；公告支持空状态；OS 不能跳回官网。受限系统访问由明确安全部署承载。

08｜验收标准：把“好看”与“可上线”分开

维度必须通过验证方式
