# Workspace First Principle
BCOS 不是传统后台管理系统，而是知识工作台（Knowledge Workspace）。
- Split View (分栏)
- Side Panel Inspector (侧边检查器)
- Inline Edit (就地自动保存)
- 减少弹窗与多层页面跳转
