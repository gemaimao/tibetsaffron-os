# Project

Brand Content OS（BCOS）是一套面向品牌建设的 Brand Operating System。
它不是 CMS。
不是知识库。
不是文档管理工具。
而是一套以 Brand Asset 为核心的数据系统。
系统中的每一条品牌知识，都是一个独立 Asset。
所有官网、宣传册、新闻稿、PPT、自媒体、视频脚本等输出，都引用这些 Asset，而不是重新编写。
BCOS 是品牌唯一可信源（Single Source of Truth, SSOT）。

# Core Principles

## Asset First
所有内容首先都是 Asset。不是文章，不是页面，不是宣传册。

## Single Source of Truth
一个知识点，只有一个正式版本。

## Composable
所有输出，全部由 Asset 动态组合。

## Versioned
所有 Asset 拥有独立版本、历史与 Release。
