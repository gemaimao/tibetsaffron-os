# 藏红花 · 种植法演进（林芝设施农艺）

> **归属**：KNO / 现代农法 ｜ **更新**：2026-08-19 ｜ 状态：定稿

## 溯源
- **种球来源**：2016 年，从**西班牙拉曼查**采购种球。
- **落地**：2016 至 2017，在崇明岛试种，实现**季风气候区**的落地化种植。

## 试种与定型（2018 起）
- 藏红花到林芝巴宜区米瑞乡**广久村**时，采用**双试种**模式：**伊朗传统大田种植 ＋ 崇明岛两段式种植**。
- **传统大田模式最终被取消**，原因：
  1. 冬春**积温不足**，球茎**发育慢**；
  2. **病虫害、霉变病**。
- **最终形成的种植法**（在两段式基础上）：
  - **营养生长阶段**：大田加**保温防雨膜棚**；
  - **休眠和开花阶段**：在**温室**中进行。

## 当前阶段（一体式设施农业）
- 林芝藏红花种植法正在**一体式设施农业**阶段——**营养生长、休眠、开花等都在一体式温室环境中进行**。
- **一体式设施农业 ≠ 真正的可控环境农业（CEA）**：
  - 一体式设施农业是一种**折衷**：以**土壤培植基质**为主，保留**土壤成分与风味特点**；
  - **尽可能降低对自然风土的模拟程度，而更接近于真实**；
  - **成本也相对较低**。
  - 而真·CEA 是全人工/无土/营养液/高度模拟自然，成本更高，也往往更"人造"。

## 演进图
```
2016 西班牙拉曼查采购种球
2016-17 崇明岛试种（季风气候区落地）
2018 双试种：伊朗传统大田 ＋ 崇明两段式
       │  传统大田：冬春积温不足/球茎发育慢/病虫害/霉变 → 放弃
       ▼
两段式·定型：营养生长(大田＋保温防雨膜棚) → 休眠·开花(温室)
       │
       ▼
一体式设施农业(今)：营养生长 · 休眠 · 开花，一体式温室完成
       ※ 折衷：土质培植基质 / 保留土壤成分与风味 / 少模拟自然风土、更接近真实 / 成本较低
```

## 关键要点
- 种植法从"能不能种活"演进到"能不能稳定、可重复"。
- **一体式设施农业**是折衷：设施（温室）保障可控，但**以土壤培植为主**，保留土壤成分与风味、贴近真实风土，而非全人造。
