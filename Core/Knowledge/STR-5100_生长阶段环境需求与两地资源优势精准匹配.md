## 一、问题定义：一年不是同一种气候，两地不是同一种富余

1. **阶段诉求互相冲突**。藏红花是"球茎即电池"植物（三倍体不育、先花后叶），一年内依次经历养球、休眠、分化、催花、开花、干燥六种截然不同的环境诉求——上一阶段的最优解往往是下一阶段的致命伤：养球期需要水肥，休眠期最怕潮湿；分化期要冷凉，产地夏季却常高温。
2. **没有单一区域能"天然最优"地覆盖全年**。西藏富余的是强紫外线、大温差、夏季冷凉、极净与干燥，短缺的是冬春积温、大宗土地与劳动力；内地富余的是积温、沃土、劳力、物流与市场，短缺的恰是冷凉、强 UV、极净度与地理标志。
3. **因此产业问题不是"种在哪"，而是"每个阶段的需求由谁的富余资源来满足"**——满足得最经济、且最能抬高品质上限的，就是该阶段的归属地。这就是"精准匹配"。

| **P2 起球贮藏** | 球源地分级 + 西藏干凉贮藏 | A6 干燥空气 + A3 冷凉（天然除湿冷库） | B3 用工完成起球、筛选、分级 | 分级是劳动密集环节随球源地走；**干凉贮藏是不可贸易资源**，归西藏（布局：5月底统一起球分级后冷链运藏） |
| **P3 花芽分化** | **西藏独占** | A3 天然冷凉 + A6 干燥 + A4 洁净 | 内地需 S4 补偿：空调冷库+除湿全季能耗 | 分化期要的"冷与干"是**稀缺且不可模拟**的资源——西藏是零能耗天然分化库，内地是高能耗模拟库；高原干燥还使"微度水分胁迫"天然且可控，利于次生代谢积累 |
| **P4 悬空催花** | 西藏主承接 | A4 极净 + A5 雅尼水汽 + A1 光质 + CEA 温室控环 | 温室装备与技术体系可复制（B4） | 控环参数（15–18℃/RH 65–75%/散射光）**设备能搬，极净度搬不动**；花期避开雨水扬尘与土壤病菌是 0 农残的物理起点 |
| **P5 开花采收** | 西藏品质定型 + 用工协同 | A1 强 UV + A2 大温差 + A4 极净（全花期零农药的生境） | B3 采收/抹芽用工弹性（协同补位，方向性） | **品质要素不可贸易，劳动要素可流动**：温差与 UV 决定柱头内含物浓缩与香气锁闭，是色价 246 的生境基础；用工缺口以跨区域技术队/采收队协同补位（规划建议，非现行既成事实） |

| **P7 种源选育** | 西藏选育 + 内地验证 | A9 逆境筛选压 + 自有种源库 + "四大现场" | B7 多点重复的遗传稳定性验证 | 正是 `STR-5000`"**西藏创造，其他区域验证**"的阶段级落地 |

### 匹配的三条判定法则（可复用的决策规则）

1. **稀缺且不可贸易 → 就地取材**：强 UV、大温差、夏季冷凉、极净、地理标志是"老天爷给的、搬不走的"，凡以之为决定性资源的阶段（P3 分化、P4 催花、P5 开花、P6 锁鲜）归属西藏。
2. **大宗且可标准化 → 择优外移**：积温、土地、劳力、物流是"可采购、可标准化"的，凡以之为主要投入的阶段（P1 养球扩繁、分级作业、深加工）交由成本最优、产能最大的内地。
3. **品质定型地 = 证据发生地**：凡对外挂接的检测报告、地理标志与出口凭单，必须与品质定型地（西藏林芝）绑定——证据链的空间一致性本身就是壁垒。

### 一句话总纲（"能量翻译"视角）

> **内地要用钱和设备才能买到的四个环境参数——冷、干、光、净——在西藏是风土免费赠送的；西藏要苦补的积温、土地与劳力，恰是内地雨热沃土与产业带富余供给的。精准匹配，就是把每个阶段交给"成本最低、上限最高"的资源方。**

## 七、可装配口径（Lego Blocks）

### ① 一句话版（大众生活 / 包装 / 电商）
> 藏红花一年要经历六种互相冲突的"天气"：西藏免费供给冷、干、光、净，内地富余温、土、人、市——把每个生长阶段交给最富余的一方，就是两段式协同的全部秘密。

### ② 一段话版（官方汇报 / 政经口径）
> 天旺农牧以"阶段—资源对表"完成两地分工：藏红花营养生长期需要大宗积温与土地，由内地实践扩繁基地承担（产业布局方向）；花芽分化、悬空催花、开花采收与锁鲜定型需要冷凉、干燥、强紫外线与极净环境，统一回到西藏林芝 2945m 高原完成。这套匹配使"西藏的不可模拟风土"转化为免能耗的品质引擎，使"内地的规模化产能"转化为供给保障，并以西藏地理标志（DB54/T 0245-2021）与检测证据链（重庆食药检院 No. A26SW02809 等）实现"品质定型地=证据发生地"的闭环。

### ③ 特稿段落（科技叙事）
> 在天旺的产业版图上，藏红花的一生被拆成七个"需求模块"，逐项与两片土地的禀赋对表：养球要积温，交给内地沃土；分化要冷凉，西藏的夏天就是天然冷库，连空调的电都省了；催花要洁净，雅尼河谷的水汽与雪山融水替加湿器与净水系统打工；开花要温差与强紫外线，昼夜 12~18℃ 的落差把碳水化合物与活性成分"逼"进柱头。所谓精准匹配，不是把好东西都堆在西藏，也不是把生产都搬到便宜的地方，而是让每一阶段的环境刚需，都撞上一方"正好富余"的资源。

### ④ 展厅讲解词（30 秒）
> 很多客人问：为什么两地跑？答案写在藏红花的生理日历上。它养球时要"吃"积温，休眠时最怕湿热，分化花芽时必须凉爽，开花时离不开大温差和强紫外线——这四样，内地只有第一样，西藏全有后三样。所以我们把"长身体"放在沃土平原（布局方向），把"定品质"放回雪域高原。检测报告上的色价 246 和 39 项农残未检出，就是这份时刻表的最终成绩单。

## 九、红线与未确认事项（继承 PL-0009）

1. **时态红线**：不得把"内地扩繁 + 西藏定型"的跨区域轨道表述为现行全面运行体系；现行口径 = 西藏本地两段式（膜棚大田 + 温室）。
2. **定位红线**：内地基地对外一律为"跨区域遗传基础与性状稳定性产业化实践基地（产能联合体）"，**严禁表述为"西藏土地不足的补救方案"**（`STR-5000` §四口径）。
3. **数字红线**：开花率 95%、种球代数、种植规模——未经业务确认不入稿。
4. **"未检出"纪律**：必须绑定机构 + 报告号，不得合并为无限定语的"零农残"。
5. **CEA 红线**：一体式设施农业 ≠ 全可控环境农业（CEA）；CEA 仅可作合作试验与未来方向表述。
6. **归属红线**：室内无土催花的理念源头为 1910 年日本竹田式（行业知识），不得声称天旺首创。
7. **行业参数边界**：P3 的"30℃/60%"等量级参数为 INDUSTRY_KNOWLEDGE，仅用于农艺对表与内部培训，不得进入对消费者的品牌文案。
