# Core/Standards —— 标准与专利工作空间

> **Mission**: 天旺农牧标准工程与知识产权布局的唯一知识工作空间。
> 支撑从企标完善 → 地方标准升级 → 国际产业联盟标准培育的全流程对标、起草与决策。
> **成立背景**: 2026-09-26，基于《藏红花国内外现行标准汇总清单》调研与《国际标准格局与中国突破战略》分析（见 STD-6000 / STD-6100）。

---

## 战略定位（一句话）

国际通用标准（ISO/CXS）层面由中国主导并不现实——标准话语权是产业基础面的平衡产物；
但**不走标准化与技术专利之路，中国藏红花产业没有出路**。
突破口：在**国际藏红花产业联盟**层面，建立对联盟有效、对统一市场有效的
品质、等级、深加工标准。本工作空间就是这条路线的知识弹药库。

## 治理默认值

- 底层标准文本（GB/ISO/CXS/药典原文）→ `INDUSTRY_KNOWLEDGE`
- 自研对标分析、培育路径、草案 → `BRAND_OWNED`
- 战略判断与路线建议 → `STRATEGIC_DIRECTION`（Claim Control）
- 涉及具体产能/市场数据 → 必须注明来源，无法核验的标注 **待核验**，禁止升格 CONFIRMED_FACT
