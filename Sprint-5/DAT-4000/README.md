## 一、定位

DAT-4000 不记录“怎么种”。

它记录：**藏红花生命过程在农业系统中的关键控制变量。**

**核心目标**：建立
种质输入 ↓ 环境控制 ↓ 生命响应 ↓ 生产结果 ↓ 品质输出
的数据链。

---

## 二、数据模型总览

采用五层结构：
L1 种质层 ↓ L2 球茎繁育层 ↓ L3 生长环境层 ↓ L4 花期管理层 ↓ L5 品质结果层

---

### L1 种质数据（Germplasm）

**记录对象**：藏红花球茎资源。

| 数据项 | 类型 |
| :--- | :--- |
| 来源地区 | Text |
| 品种/种源编号 | ID |
| 引入年份 | Year |
| 适应代数 | Number |
| 球茎等级 | Enum |
| 初始重量 | g |
| 芽眼数量 | Number |

**核心指标**：种质适应性指数
**用途**：评价不同来源球茎在新环境中的表现。

---

### L2 球茎繁育数据（Corm Development）

（这是藏红花农业的核心。）

| 数据项 | 类型 |
| :--- | :--- |
| 母球重量 | g |
| 子球数量 | 个 |
| 子球平均重量 | g |
| 繁殖系数 | Ratio |
| 球茎增重率 | % |
| 病害率 | % |

**核心指标**：繁殖系数
**公式**：子球数量 ÷ 母球数量
**目标**：形成高健康、高繁殖能力种球体系。

---

### L3 生长环境数据（Growth Environment）

对应 CEA 和基地环境。

**温度**
* 日平均温度
* 最高温度
* 最低温度
* 积温

**光环境**
* 光照强度
* 日照时间
* UV强度

**水分**
* 土壤湿度
* 灌溉量
* 降雨量

**土壤**
* pH
* EC值
* 有机质
* 氮磷钾

---

### L4 花期管理数据（Flowering Management）

（重点：温室开花阶段。）

| 数据项 | 类型 |
| :--- | :--- |
| 入棚时间 | Date |
| 温控曲线 | Data |
| 湿度曲线 | Data |
| 花芽状态 | Stage |
| 开花率 | % |
| 单球花数 | Number |
| 采收窗口 | Day |

**核心指标**：花期效率
**包括**：开花率、同期开花比例、采收效率

---

### L5 品质输出数据（Quality Output）

（连接 KU-5000。）

| 数据项 | 类型 |
| :--- | :--- |
| 花柱重量 | mg |
| 水分 | % |
| Crocin | mg/g |
| Picrocrocin | mg/g |
| Safranal | mg/g |
| ISO等级 | Grade |

---

## 三、技术模型

DAT-4000 最终形成：
**藏红花农业数字孪生模型**

球茎状态 + 环境状态 + 管理过程
↓
预测：繁育结果 + 开花结果 + 品质结果

---

## 四、核心指标体系

建立三大农业 KPI：

### ① 繁育 KPI
**关注**：球茎数量增长。
**指标**：繁殖系数、子球重量

### ② 开花 KPI
**关注**：花产量。
**指标**：开花率、单球花数、花期集中度

### ③ 品质 KPI
**关注**：产品价值。
**指标**：双苷指标、ISO等级
