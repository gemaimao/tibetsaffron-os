## 一、数据目标

DAT-3100 不用于证明“某个地方一定更好”。

它用于建立：
**产区环境 → 植物响应 → 品质表现** 之间的核心数据关联。

---

## 二、数据结构

### 01 地理基础数据（Geo）

| 参数 | 数据类型 | 用途 |
| :--- | :--- | :--- |
| 经纬度 | GPS | 定位产区 |
| 海拔 | m | 地理梯度 |
| 河流距离 | m/km | 水文影响 |
| 地形类型 | Enum | 河谷/坡地/台地 |
| 坡向 | Enum | 光照差异 |
| 坡度 | ° | 排水条件 |

---

### 02 光热数据（Climate Energy）

| 参数 | 数据类型 | 用途 |
| :--- | :--- | :--- |
| 年均温 | ℃ | 基础气候 |
| 生长期平均温度 | ℃ | 生长评价 |
| 开花期温度 | ℃ | 花期影响 |
| 年积温 | ℃·d | 生育评价 |
| 昼夜温差 | ℃ | 代谢影响 |
| 日照时数 | h | 光合作用 |
| UV指数 | Index | 次生代谢 |

---

## 三、核心数据关系

DAT-3100 最终形成：

```
风土输入
↓
环境变量
↓
植物响应
↓
品质输出
```
