## 二、逐段页面设计

### S0 · 开场：总命题（Cesium Hero）
- **场景**：Cesium 地球自太空缓慢旋转，镜头俯冲青藏高原，最终落向林芝·米瑞乡
- **命题动画**（SVG 文字逐句浮现）：
  > 名字指向一片土地，不等于回家。
  > 把它带到这片土地，也不等于回家。
  > 只有当它在这里适应环境、完成生命循环、形成稳定的生产节律——
  > 回家，才从一个文化想象，变成正在发生的现实。
- **交互**：滚动进入第一问；右上角常驻「知识库系统」入口图标（→ /os，OS 保留）

### S1 · 第一问：名字为什么指向这里？（SVG 时间轴 × Cesium 航线）
- **左**：SVG「261 年命名史时间轴」——文献节点随滚动点亮（"藏红花"之名如何长期指向这片土地）
- **右/背景**：Cesium 历史航线——波斯（伊朗）→ 丝绸之路 → 西藏，虚线路径缓缓生长
- **文案核心**：名字不是原产地证明，而是一种历史形成的文化指向与语言召唤
- **诚实边界角标**：明确标注"文化事实 ≠ 地理事实"

### S2 · 第二问：土地为什么可能接纳它？（Cesium 主场）
- **Cesium 回家之路第一站**：
  - 🌱 崇明养球基地（平原，31.62°N, 121.40°E）
  - 🏭 米瑞乡基地（2945m，29.62°N, 94.47°E）
  - 💧 雅尼汇流（雅鲁藏布江×尼洋河，29.59°N, 94.44°E）
  - ⛰️ 苯日神山（29.60°N, 94.35°E）
- **SVG 生态机理角标**（三个小动画）：
  - ☀️ 3000m 强紫外线 → 刺激 Crocin 富集
  - 🌡️ 昼夜温差 → 锁住 Safranal 香气
  - 💨 雅尼热岛微气候 + 冲积沙质土
- **数据弹层**：点击基地 → 海拔 2945m、0 农残 SCI-001、两段式农艺说明
- **文案核心**：2018 年至今，用种球一轮又一轮的生命循环回答"藏地能否承接它"

### S3 · 第三问：生命如何证明它已经留下？（SVG 主场）
- **全屏 SVG 生命循环动画**：种球埋入 → 发芽 → 抽薹 → 开花 → 采收 → 新球形成 → 再迭代（循环不止）
- **八代迭代时间轴**：2018 → 2026，一代一代点亮，每代标注关键节点
  - 第一代是尝试；第二代是延续；第三、四代出现连续性；第八、九代……
- **交互**：拖动时间轴回看每一代
- **文案核心**：八次生命循环 = 藏红花与西藏的八次相互确认；**"这条生命线没有断"**
- **科学纪律**：使用"稳定表型 / 生产节律"，标注"西藏适应性现象——已观察、待科学验证"

### S4 · 第四问：技术如何让这种关系稳定？（KG 主场）
- **全屏 KG 图谱**（SVG 力导向图）：
  - 节点：两段式现代农艺 / CEA 控环生命工程 / 极地风土算法 / STR-4000 五层壁垒
  - 关系边动画：从"偶然适应"连接到"可复现生产"
- **钻取**：点击节点 → brand/agronomy.html、brand/patents.html 详情
- **文案核心**：天旺不只是先到了，而是把生态关系稳定下来的工程承担者

### S5 · 第五问：最终它将为这片土地带来什么？（KG 主场）
- **KG 证据图谱**：7 级证据效力层级（CMP-001 海关凭证 → SCI-001 0农残 → IND-001 农户工资 → VIS-001 现场）金字塔式呈现
- **合作网络**（Cesium 地理连线）：香港宝芝林、劲牌、加拿大出口（CMP-001，单克 128.2 元）
- **文案核心**："藏"字完成转变：语言地理指向 → 产区关系、生态关系、生命关系、价值关系

### S6 · 天旺的角色（SVG 收束）
- **五重正当性矩阵**：语言回家 / 生态回家 / 生命回家 / 技术回家 / 价值回家（五列，逐列点亮）
- **逻辑链**：文化召唤 → 生态适应 → 生命扎根 → 技术稳定 → 价值涌现
- **核心句**（终幕大字）：
  > 我们不是因为先到了，所以宣布它回家。
  > 恰恰相反，我们用了近十年时间，去证明它是否真的能够回家。

## 三、技术实现方案

| 层 | 技术 | 说明 |
|----|------|------|
| 空间 | Cesium（CDN 1.107，沿用项目现状） | 复用 kailash 项目 `spatial_narrative.js` 引擎模式（场域状态机/巡航/锚点弹层） |
| 生命 | 手写 SVG + CSS keyframes / SMIL | 生命循环、八代时间轴、命名史、分子机理——无第三方动画库 |
| 关系 | 自绘 SVG 力导向图（轻量） | KG 图谱自绘（避免新依赖）；节点点击钻取详情 |
| 滚动 | IntersectionObserver 自写滚动绑定 | 长卷分段推进，不引 GSAP（保持零框架现状） |
| 数据 | `geo-anchors.json` + `relations.json` | 地理锚点（坐标↔资产）；资产关系边（asset↔asset） |
| 集成 | /os 入口保留 | 知识库操作系统功能不动 |
