西藏藏红花·地理标志一级品认证

EVD-003 法律效力 Class C ｜ 科技研发背书

藏红花多糖·斑马鱼生物模型辅助降糖实验

苏州飞凡检测依据国标 GB/T 39649-2020 建立斑马鱼高糖生物模型。在 2000 μg/mL 最大安全浓度下，藏红花多糖压片糖果处理组组织液血糖降低 66.74% (P < 0.001)，获科研功效认证证书。

支持结论：在斑马鱼实验模型条件下具有辅助降低血糖活性的表现。
禁止宣称：严禁宣称降糖药品疗效、严禁自动推导人体临床等效。
飞凡检测辅助降血糖功效认证证书 (证书校验码: 14766127)
报告单号: FFZ202501145 | 证书校验码: 14766127 (2025.10.20)
EVD-004 法律效力 Class C ｜ 科技研发背书

藏红花多酚·斑马鱼生物模型降尿酸实验

苏州飞凡检测依据国标建立斑马鱼高尿酸模型（氧嗪酸钾+黄嘌呤诱导）。在 2000 μg/mL 浓度下，藏红花多酚压片糖果处理组尿酸值减少 7.07% (P = 0.00705 < 0.01)，获降尿酸功效证书。

支持结论：在特定斑马鱼高尿酸模型实验中显示出降低尿酸的活性反应。
禁止宣称：严禁宣称治疗痛风、严禁夸大为人体临床等效结果。
