# Reference Rule

KU 不复制任何知识内容。

KU 仅建立引用关系。

所有知识内容维护于各 KNO 文档。

当 KNO 更新时，KU 自动引用最新版本。

---

# Repository Rule

KU-1000 为 Brand Content OS 根知识节点。

后续所有 KU 应遵循相同 Mapping 机制：

```
KU
    ↓
KNO（引用）
```

禁止在 KU 中维护重复知识。
